# backpack-inventory-system
Programming in C project 1

Basically this project will be a pseudo backpack that a student can use to store their school supplies. 
The program will prompt the user if they want to add or remove items from their backpack.
The backpack can have different spots where you can put different items, such as folders and notebooks in one spot and pens and a calculator in another spot.
Each spot will have a maximum capacity of items that can be stored in it. 
The user can view the contents of each part of the backpack and see how full it is. 
We will have to figure out a way to keep track of the items in the backpack between program runs. 
There will be a main loop that runs until the user decides to exit the program, and again their changes will be saved between uses. 
The main choices the user will make will be adding/removing, viewing the contents of the backpack, and exiting the program. 
This program may or may not use functins to help organize the code.
The entire thing will also run in the terminal, thouugh if we have time we could maybe add a simple user interface that pops up in the terminal.
